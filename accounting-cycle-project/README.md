# Accounting Cycle Project

## Objective

To demonstrate the complete accounting cycle using a fictional business.

## Process

1. Record business transactions
2. Prepare journal entries
3. Post entries to ledgers
4. Prepare the trial balance
5. Pass adjusting entries
6. Prepare the Profit & Loss Account
7. Prepare the Balance Sheet

## Skills Demonstrated

- Journal entries
- Ledger posting
- Trial balance
- Adjustments
- Financial statements
- Excel-based accounting
